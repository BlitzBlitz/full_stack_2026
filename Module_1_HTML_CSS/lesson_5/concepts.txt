CSS: Cascading Style Sheet 

What:   Dokument ku deklarohet stilimi i elementeve
Why:    Per ta zbukuruar faqen
How:    
        1. Krijojme nje file(dokument) me prapashtese '.css' brenda folderit(dosjes) ku ndodhet index.html
        2. Bejme lidhjen HTML <-> CSS
            <link rel="stylesheet" href="styles.css" />
        3. Selektojme elementin qe do stilojme
            3a. Select by tag
            3b. Select by class [me e perdorura ne praktike]
            3c. Selectimi me id
        4. Vendosim stilimin



Extra: top 5 extention per VS code, 
       top 15 keyboard shortcuts for vs code


Rradha e punes:
1. Ndajme elementet ne kontenier
2. vendosim elementet ne html
3. stilojme ne css
    3a. Layout -> Vendosja e elementeve
        3a.a Ndarja ne kontenier 
        
        3a.b WIDTH 
                Element: 
                    block elements: 
                        zene te gjithe hapsiren width: 100% by default
                        mund tju ndryshohet width
                    inline elements: zene aq hapsire sa ju duhet
                        nuk mund tju ndryshohet width
                    inline-block
        
        3a.c Spacing
                Padding: hapsira nga brenda kornizes(border)
                Margin:  hapsira nga jashte kornizes(border)

        3a.d Positioning ne grup[per direct-child]
                3ad.1 vendos borders
                3ad,2 Positioning me flex
                        flex-direction
                        justify-content     [pozicionim horizontal]
                        align-items         [pozicionim vertikal]
        3a.e Positioning individual

Responsive Design:
    1. Perdorimi i relative units(njesi te varura)
        1a. % -> varet nga gjersia e parent container       [width]
        1b. em -> varet nga font-size e parent container    [padding/margin] [1em ~= 16px]
        1c. rem -> varet nga font-size e root elementit(html) [font-size]    [1rem ~= 16px]
        1d. vh -> varet nga gjersia e viewportit                  [height]      [1vh = 1% e viewport height]
        
        Fixed units(njesi fikse)
        1e. px -> pixels
    
    2.  Ndryshimi i drejtimit te konteniereve 
            flex-direction: row -> column
    3.  Ndryshimi i madhesise se elementeve
            width: 50% -> width: 100%
            width: 15% -> width: 50% / 25%
    4.  Ulim hapsiren e elementeve
            padding: 20px -> padding: 10px
            margin: 20px -> margin: 10px
    5.  perodim media queries
        @media screen and (max-width: 768px) {
            .container {
                flex-direction: column;
            }
        }
